# 🤝 PeerHub — Interactive Skill Exchange Platform

> **Thirduni MVP Project — October 2026**

## 📖 Project Overview
PeerHub solves the problem of passive, non-interactive online courses by establishing a live, peer-to-peer skill exchange ecosystem. It connects users through a **Skill Barter Economy** where users trade knowledge directly (e.g., teaching Python in exchange for learning Spanish).

## ✨ Key Features
* **Teach vs. Learn Matching Engine:** Connects complementary user skills.
* **Skill Credits / Hour Bank:** Earn and spend hours based on active participation.
* **Reliable Partner Badge:** Gamified accountability system to track commitment.
* **Excuse Management System:** Structured handling of session rescheduling.

## 🛠️ Tech Stack
* **Frontend & Backend:** Python, Streamlit
* **Version Control:** GitHub
* **Cloud Hosting:** Streamlit Community Cloud
